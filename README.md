# Ideal World – app pages

Public pages for apps by Adarsh Kumar. Every app keeps all of its files in its own folder:

- `master-g/` – Master G
  - `privacy.html`, `delete-account.html`, `index.html`
  - `app-ads.txt` (AdMob)
  - `store-listing/` – Play Store icon, feature graphic and listing text

Add a new app by creating a new folder with the same layout.

Served with GitHub Pages: https://adarshk47.github.io/Idealworld/
